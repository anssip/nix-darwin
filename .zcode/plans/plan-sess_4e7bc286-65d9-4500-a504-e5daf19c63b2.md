Fix the nordvpn-cli install failure on this Mac.

**Why it fails:** install.sh writes `/usr/local/bin/nordvpn` via `curl -o` without sudo, but `/usr/local/bin` is root-owned on this machine → write denied → installer aborts → outer `curl | bash` pipe breaks with `curl: (23)`.

**Steps:**
1. Pre-seed the target file as user-owned so the installer's unprivileged write succeeds:
   - `sudo touch /usr/local/bin/nordvpn && sudo chown anssi:staff /usr/local/bin/nordvpn`
2. Re-run the official installer (same command as before):
   - `curl -fsSL https://raw.githubusercontent.com/gonzalopezgil/nordvpn-cli/main/install.sh | bash`
   - It will prompt once for the sudo password (helper + sudoers steps) and then download ~160 MB of OpenVPN configs into `~/.nordvpn/ovpn`.
3. Verify: `command -v nordvpn && nordvpn --help` (or `nordvpn status`).

- This is the unofficial third-party tool you picked; it installs a passwordless-sudo rule (`/etc/sudoers.d/nordvpn`) for its privileged helper, and downloads are unchecksummed. We'll keep its install flow untouched (only pre-seeding the one file it fails to write).
